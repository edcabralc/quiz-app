# Projeto Quiz - Curso CJRM

Este é um projeto simples de um **quiz interativo**, desenvolvido como parte do curso CJRM. O objetivo do projeto foi aplicar conceitos aprendidos sobre **eventos** e **manipulação do DOM** em JavaScript.

## Descrição

O quiz consiste em uma série de perguntas, e o usuário deve escolher a resposta correta. A pontuação é exibida no final com base nas respostas dadas. O projeto utiliza HTML para a estrutura da página, CSS para o estilo e JavaScript para a interação com o usuário.

## Funcionalidades

- Exibição de perguntas e alternativas.
- O usuário pode selecionar uma resposta e ver se está correta.
- Pontuação acumulada que é mostrada ao final do quiz.

## Tecnologias Utilizadas

- **HTML**: Para estruturar a página do quiz.
- **CSS**: Para estilizar a página e tornar a interface mais agradável.
- **JavaScript**: Para manipulação do DOM e eventos, controle da lógica do quiz e cálculo da pontuação.

## Como Rodar

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em seu navegador preferido.
3. O quiz será carregado automaticamente. Comece a responder às perguntas!

## Estrutura do Projeto

/quiz-cjrm
    ├── index.html      # Página principal do quiz
    ├── style.css       # Arquivo de estilo
    ├── script.js       # Lógica em JavaScript para o quiz


## O que Aprendi

- **Eventos**: Como lidar com interações do usuário, como cliques e seleções de respostas, utilizando eventos em JavaScript.
- **Manipulação do DOM**: Como modificar a estrutura da página dinamicamente com base nas interações do usuário, como atualizar a pontuação ou mostrar a próxima pergunta.
